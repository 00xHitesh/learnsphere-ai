# Routing

Lumen uses **TanStack Router** with file-based routing. Route files live in `src/routes/`.

---

## File Naming Conventions

| Pattern | Meaning | Example |
|---|---|---|
| `index.tsx` | Index route for its parent path | `courses.index.tsx` → `/courses` |
| `$param.tsx` | Dynamic route segment | `courses.$slug.tsx` → `/courses/:slug` |
| `parent.child.tsx` | Dot-notation nesting | `admin.courses.tsx` → `/admin/courses` |
| `__root.tsx` | Root layout (wraps everything) | — |

## Layout Routes

**`__root.tsx`** wraps the entire app with `<Layout>` (Header + Footer + Chatbot) and mounts the `<Toaster>`.

**`courses.tsx`** is a layout route that renders `<Outlet />` for `/courses` sub-routes.

**`admin.tsx`** is both a layout and a content route:
- At `/admin` it renders the Overview component directly.
- At `/admin/*` it renders `<Outlet />` for sub-routes.
- It guards access so only `role === "admin"` users can proceed.

## Search Params

The learn page uses typed search params:

```ts
// learn.$slug.tsx
type LearnSearch = { lesson?: string; quiz?: string };
```

Navigate to a specific lesson: `/learn/foundations-of-typescript?lesson=l-0-why-types`
